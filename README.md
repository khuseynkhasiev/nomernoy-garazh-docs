# Документы игры «Номерной гараж»

Публичные документы GrozX для игроков и модерации RuStore.

- `index.html` — политика конфиденциальности.
- `consent.html` — согласие на отправку диагностики.
- `sdk.html` — сведения о сторонних библиотеках.

Сайт состоит из статических HTML-страниц. Сборка и зависимости не требуются.

## Публикация на GitHub Pages

1. Разместить файлы в корне отдельного публичного репозитория `nomernoy-garazh-docs`.
2. Открыть Settings → Pages.
3. В Build and deployment выбрать Deploy from a branch.
4. Выбрать ветку main и папку / (root), затем Save.
5. Дождаться завершения публикации и открыть адрес через Visit site.
6. Проверить главную страницу и обе ссылки на дополнительные документы без входа в GitHub.

В RuStore указывается адрес опубликованной главной страницы GitHub Pages, а не адрес репозитория.

Не добавлять в этот репозиторий исходники игры, APK, сохранения, ключи подписи и токены SDK.
